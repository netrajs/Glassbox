# Changelog

## 0.1.0

First release.

- Review mode: Claude pauses before every edit; approve or redirect from the panel or right above the code.
- The Stage: each edit plays in the editor (old code red → erased → new code typed in green → BEFORE / AFTER).
- Watch mode: changes play live while Claude works; Pause, Resume, Stop and Tell Claude at any moment.
- Explanations (what / why), Ask about any change, and quick quizzes, using the Claude API.
- Timeline: every change saved; replay one change or a whole session; click to open the code.
- Blind Spots: tracks which AI-written code you've reviewed; Explorer badges and per-file walkthroughs.
- Glassbox Web (`npx glassbox`) for terminal and Claude desktop app users.
- Optional recording of changes made by other AI tools.
- Voice: read explanations aloud.
